## Overview

The **Function Word DNA Compressor** analyzes the syntactic ratio of content words (nouns, action verbs, domain terms) to function words (prepositions, auxiliary verbs, pronouns), driving lexical density up to $\ge 55\%$ for ultra-high-signal technical documentation and pull requests.

## Core Patterns

- **55% Lexical Density Benchmark**: Enforce high content-to-glue ratio.
- **Auxiliary Verb Pruning**: Replace "is responsible for" with direct action verbs.
- **Dummy Pronoun Elimination**: Purge "there is" and "what we want to do".
